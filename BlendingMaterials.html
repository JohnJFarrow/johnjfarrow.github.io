Blend Materials

Introduction

A blend material is one which combines multiple material instances and controls the way in which they mix together to produce the final color.

These are the steps to import textures from Quixel and blend them into one Unreal material instance.

Importing from Quixel

In this example we are applying our blend material to a road, so we want 3 Quixel textures which could be used on a road. The Unreal material instance blends 1, 2 or 3 materials - here we will be using 3.

👉Use the Window | Quixel Bridge menu to open Quixel.

👉On the right hand tree view select Surfaces | Asphalt to display surfaces:

We want to select 3 materials:

  • Rough Asphalt for the base layer (asset id wjvnagr)
  • Damaged Asphalt for the middle layer (asset id vizcebf)
  • Destroyed Asphalt for the top layer (asset id sinobcga)

👉Click on each of these and click the Download button the the Add button to download the texture and add it to the project.

👉Minimize the Quixel window.

The materials which we added now appear in the Unreal content browser as material instances, like so:

For the next step we need to select mutiple material instances, one way to do this is to select the Surfaces directory and use a filter which selects only material instances, so we see this:

Selecting Material Instances

We need to select 3 material instances to blend. The order in which they are selected determines the role they play in the blend material.

  • 👉first select the base layer MI_Rough_Asphalt_wjvnagr_2K
  • 👉then select the second layer MI_Damaged_Asphalt_vizcebf_2K (by control-clicking on it)
  • 👉then select the third layer MI_Destroyed_Asphalt_sinobcga_2K (by control-clicking on it)

With these there material instances selected:

👉 Use Window | Quixel Bridge to open the Quixel window

👉 In the Quixel window, on the left side tree view select Surfaces | Asphalt | Fine and click on the first surface; all we want here is for the right hand window to appear with the selected asset - which asset is chosen does not matter:

👉 In the right side next to "Medium Quality" is a small button, click this:

This will open the Megascans window:

When we press the "Create Material Blend" button this will create the material with the name specified by the "Material Name" property in the directory specified by the "Destination Path" property.

👉Set the material name and path, then press the "Create Material Blend" button

Pressing the button creates the material in the specified folder. Using the defaults will create the material in a (possibly) new folder in the content browser. If we open that material and open and click on the "02 - Base Layer", "O3 - Middle Layer" and "04 - Top Layer" we can should see the new material is using the material instances we selected:

Using the Material

To test the material we need a mesh to drop it on.

👉Change to Modeling Mode using the dropdown on the toolbar:

👉click the Rectangle option 👉change the Width Subdivisions and Depth Subdivisions to 100
👉change the material to the one we just created

The rectangle creation should look like this:

👉click the Accept button to create the rectangle
👉duplicate it many times using the XForm | Pattern option to create a small road-like strip:

This creates one mesh for some length of the road.

Just resizing the first rectangle to the size of a long road will not work - if you view the result in the viewport with Wireframe on you will see this extends the triangles in the mesh to the length of the road. Mesh painting applies colors at vertices not the faces, so we need more vertices than this approach provides.

Mesh Painting

Once we have create the mesh for the road section and applied our blend material we have this:

Mesh painting is one way to change the appearance of the material we are using, and to control the mixing of the 3 material instances which make up the blend material.

👉Change to Mesh Paint Mode using the dropdown on the toolbar:

👉With the Colors tab selected click the Paint icon to display the painting options:

The most important thing here is the "Channels" section at the bottom - the selections here, despite the labelling, are not Red/Gree/Blue, they instead correspond to the channels being blended:

  • the 'red' channel corresponds to the middle layer
  • the 'green' channel corresponds to the top layer
  • the 'blue' channel corresponds to the puddle later

The Paint Color property determines if you are painting the selected color on or removing it. Painting is done by holding down the left mouse key and moving the mouse. Either press X to toggle between the two states, or hold the shift key to select the opposite state.

To use the 'blue' puddle channel first you must enable it using the 00-Global|Use Puddle Layer property.

Nanite

Mesh painting is vertex painting, i.e. colors are assigned at each vertex in the mesh. The nanite rendering process simplifies meshes by removing vertices depending on distance from the camera (and other things). So one would expect the colors to change as vertices are removed. In fact enabling nanite on a mesh such as the road example used above sets the color to the base layer material only, removing any mesh painting effects.
