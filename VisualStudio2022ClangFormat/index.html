Visual Studio 2022 - Using Clang Format

January 29, 2025

How to format code using clang format inside Visual Studio 2022.

Configuration​

Use the Tools > Options... menu

Set these options:

info

The options under Formatting such as Indentation, New Lines, Spacing, Wrapping have no effect when clang formatting is enabled.

Configuration site​

You can interactively create or modify and .clang-format file using this configurator.

From a command line check the version of clang-format installed with this command:

clang-format --version

clang-format version 18.1.8

On the configurator change the version to match the one you have installed.

Note this site allows you to upload an existing file and modify it using the Config File button then the Upload button.
