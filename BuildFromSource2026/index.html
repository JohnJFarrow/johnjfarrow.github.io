UL Building Unreal Engine From Source with Visual Studio 2026

December 10, 2025

This is a brief guide to downloading and building UE5 using git command line tools and Visual Studio 2026.

Github Account​

If you don't have a github account, go to github.com and create one.

Epic Games Account​

If you don't have an Epic Games account, go to epicgames.com/register and create one.

Connecting the Epic Games account to the Github account​

You need to connect your Epic Games account to your github account so you can get access to Epic's github repositories.

To do this:

  • sign into your Epic Games account at epicgames.com
  • click on your username near the top right corner of the page and select "Account" from the dropdown menu
  • click on "Connections" in the list of options on the left side of the page
  • select "Accounts" from the tab bar with the "Apps" and "Accounts" options
  • under the github icon click the "Connect" button. This will guide you through a series of steps to connect your Epic Games and github accounts

Installing git​

If you do not already have the git commandline tools installed, install them from git-scm.com/downloads.

Choosing and Cloning a branch or tag​

You can choose either a branch or a tag.

  • branches are listed at https://github.com/EpicGames/UnrealEngine/branches/all
  • tags are listed at https://github.com/EpicGames/UnrealEngine/tags

Note that there are branches for only major versions, such as 5.6 and 5.7, and then tags for minor versions, such as 5.7.0-release and 5.7.1-release.

Branches of note:

  • release - the latest recently released version of UE
  • ue5-main - most up to date - this is being continuously updated and won't necessarily build or run on any given day.

Decide on a branch or tag and clone it with this command:

git clone --depth=1 --single-branch -b BRANCH_NAME_OR_TAG git@github.com:EpicGames/UnrealEngine.git

Options used: -- --depth 1`` clones only the latest commit for each file -- --single-branchclones only the specific branch ---b BRANCH_NAME_OR_TAG``` specifies the branch or tag you want to clone

To clone the latest release at time of writing use:

git clone --depth=1 --single-branch -b 5.7.1-release git@github.com:EpicGames/UnrealEngine.git

Setup​

Once the git clone is complete, change into the UnrealEngine directory and run this command:

Setup.bat

Do not generate project files for the source build, we do that later for the project.

Registering without Building​

Once you have registered a source build you can change your game project to use that source build. Registration can be done without building Unreal Engine source project.

To do this run this command (the file UnrealVersionSelector-Win64-Shipping.exe was created by the Setup.bat command):

Engine\Binaries\Win64\UnrealVersionSelector-Win64-Shipping.exe

This will register the source build.

Using the source build​

In your project you need to generate project files for Visual Studio 2026, not Visual Studio 2022.

To make sure this will happen, in your project, modify your Saved\UnrealBuildTool\BuildConfiguration.xml file to have the <ProjectFileGenerator> element as shown below:

<?xml version="1.0" encoding="utf-8" ?>
<Configuration xmlns="https://www.unrealengine.com/BuildConfiguration">
  <ProjectFileGenerator>
    <Format>VisualStudio2026</Format>
  </ProjectFileGenerator>
</Configuration>

After updating the BuildConfiguration.xml, right-click your games .uproject file and change the Unreal version to your source build, this will generate new project files.

Open the .sln file in Visual Studio then:

  • select your game, right click and "Set as Startup Project"
  • select your game, right click and choose "Build"

This might be faster than building the whole solution because parts of the engine you don't use in your project won't get build unnecessarily.

Unreal Build Accelerator​

If the build fails with error messages related to the UbaSessionServer (see here) this can be disabled in Engine\Saved\UnrealBuildTool\BuildConfiguration.xml like this:

<?xml version="1.0" encoding="utf-8" ?>
<Configuration xmlns="https://www.unrealengine.com/BuildConfiguration">
    <BuildConfiguration>
	    <bAllowUBAExecutor>false</bAllowUBAExecutor>
		<bAllowUBALocalExecutor>false</bAllowUBALocalExecutor>
	</BuildConfiguration>
</Configuration>

Unregistering the Build​

To unregister a build run regedit.exe and go to this key:

HKEY_CURRENT_USER\Software\Epic Games\Unreal Engine\Builds

Registered build appear under this key:

Delete an entry to unregister that build.

Building your own fork​

From the Epic Games repo https://github.com/EpicGames/UnrealEngine fork the engine to make your own repo.

Clone that repo to your machine using:

git clone https://github.com/YourName/UnrealEngine.git

Configure the upstream repo for your repo:

git remote add upstream https://github.com/EpicGames/UnrealEngine

The command

git remote -v

Should show the upstream repos:

origin  https://github.com/YourName/UnrealEngine.git (fetch)
origin  https://github.com/YourName/UnrealEngine.git (push)
upstream https://github.com/EpicGames/UnrealEngine (fetch)
upstream https://github.com/EpicGames/UnrealEngine (push)

Fetching latest changes from the Epic Games repo​

Change to the clone of your repo and use this command:

git fetch upstream
git checkout ue5-main
git merge upstream/ue5-main

This will fetch the latest tags as well as the files.

Earlier versions​

These instructions will work for Unreal 4.27 and Visual Studio 2022. Make sure you clone the git repository then checkout the 4.27 branch before you run Setup.bat or GenerateProjectFiles.bat.

The solution file created will be called UE4.sln not UE5.sln.
